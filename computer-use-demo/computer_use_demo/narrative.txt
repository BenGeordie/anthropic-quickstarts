If you’ve tried computer use, then you know that it’s a game changer. It’s intelligent, it can perform any task that you can do on the computer, and it’s fast… for the first few iterations at least.

Each iteration gets slower because in order to do perform the actions, it must see the entire history of actions. The more actions it takes, the longer this history gets, the longer it takes to figure out the next step.

Anyone who has taken an introductory algorithms class would notice that the runtime scales quadratically with the number of steps. When your runtime increases, so does your cost, so that also scales quadratically with the number of steps.
